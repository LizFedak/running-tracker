# Runner Profile

*Update this when something changes. Claude reads it before planning each week.*

## Goal
- **Target:** build up long runs consistently and improve pace and stamina. No race scheduled.
- **Timeline:** 3–6 months, flexible. Half-marathon distance (13+ mi long runs) is the long-run milestone.
- **Last half (Oct 2026):** 2:30. Started at ~9:00/mi, then switched to run/walk. My training ran through February, until an injury. Longest training run was 10 mi.

## Current baseline (Nov 2026)
- **Weekly mileage:** inconsistent, ~5–10 mi
- **Comfortable:** 2–3 mi easy. 4–5 mi is a push.
- **Easy pace:** 10:00–13:30/mi depending on sleep. **Plan by heart-rate zone**, not pace.

## Scheduling
- Weekdays are easier for training. Long runs and quality sessions go on weekdays.
- **Weekends (son is home): only CrossFit, easy Z1–Z2 runs or rest.** No long runs, hard sessions, yoga or hikes.
- **Other activities:** CrossFit 2–3×/week, plus yoga and hiking on weekdays. Hiking miles don't count toward running miles.

## Body
- General aches and desk stiffness. Every run starts with a proper warm-up.

## Mileage rules
- Each week = previous week's planned miles **+10%** (rounded to the nearest 0.5).
- Every 4th week is a **cutback**, about 25% below the week before (weeks 5, 9, 13, 17). The week after a cutback builds 10% from the last full week.
- **Long run: never more than 16 mi.**
- If a race gets added later, add a taper before it.

## 4-week rotation
Repeats all the way through the plan (week 1 = Easy). There is one quality session per week, on a weekday, and the long run stays Z2.

| Rotation week | Type | Quality session |
|---|---|---|
| 1 | Easy | None. Easy and long runs only. From week 5 on, this is also the cutback week. |
| 2 | Strides | Easy run + 4–8×20s strides |
| 3 | Tempo | Z3–Z4 tempo segment inside an easy run |
| 4 | Hills | Easy run + short hill repeats |

## Zones
- **Z1:** recovery. Warm-up, cool-down, walk breaks.
- **Z2:** easy, conversational. Most of the miles.
- **Z3:** steady / moderate.
- **Z4:** threshold / tempo. Comfortably hard.
- **Z5:** hard. Strides and short repeats.
